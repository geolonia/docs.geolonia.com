Geolonia Mapsは、Geoloniaの提供する地図を利用できるライブラリです。まず、例を見てみましょう。

<GeoloniaMap lat={35.68} lng={139.75} zoom={11} marker="off" geojson="/data/sample-spots.geojson" cluster="on" tall={true} caption="本物の地図（localhost や GitHub Pages などの開発・プレビュー環境で描画）。東京の5スポット。" />

もっと例を見たい方は、[ハウツー](/howto/)で見ることができます。

## 3つのライブラリからスタート

Geolonia Mapsは、様々な方に使っていただけるように、コア技術に加えて3つのライブラリを提供しています。簡単なものから最先端のWeb技術まで、様々な書き方ができます。チュートリアルでは、導入する環境やすでに使っているライブラリに合わせて3つのルートを用意しています。
