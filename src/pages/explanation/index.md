## なぜ MapLibre GL JS 互換なのか

独自の閉じた API を覚えるのではなく、**世界中で使われている標準的な地図 API の知識がそのまま通用する**ということです。公式ドキュメントも読め、知識が無駄にならず、移行もしやすい。詰まったら「MapLibre ではどう書くか」で検索する——これが互換の与える一番の学び方の指針です。

## ベクトルタイルとは

地図データを正方形のタイルに分け、必要な範囲だけ配信する仕組み。なかでもベクトルタイルは「絵」ではなく「ここは道路」というデータそのものを運ぶので、拡大しても粗くならず、見た目（スタイル）を後から自由に変えられます。
