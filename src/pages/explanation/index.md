「解説」セクションでは、Geolonia Maps を使う際に知っておくとよい概念や、ある部分がなぜそうなっているのかといった背景をまとめています。

## なぜ MapLibre GL JS 互換なのか

独自の閉じた API を覚えるのではなく、**世界中で使われている標準的な地図 API の知識がそのまま通用する**ということです。公式ドキュメントも読め、知識が無駄にならず、移行もしやすい。詰まったら「MapLibre ではどう書くか」で検索する。これが、互換がもたらす学び方の指針です。

## ベクトルタイルとは

地図データを正方形のタイルに分け、必要な範囲だけ配信する仕組み。なかでもベクトルタイルは「絵」ではなく「ここは道路」というデータそのものを運ぶので、拡大しても粗くならず、見た目（スタイル）を後から自由に変えられます。

## 地図のスタイルとは

地図の見た目を決めているのがスタイルです。データと見た目が分かれているので、同じデータから明るい地図も暗い地図も作れます。仕組みは [地図のスタイルとは](/explanation/map-style/)、Geolonia が提供しているスタイルは [Geolonia Maps のスタイル一覧](/explanation/styles/) を参照してください。

## デモキーで無料で試せる環境

サンプルに出てくる `YOUR-API-KEY` が何で、どんな環境ならキーを発行せずに地図が動くのかは [デモキーで無料で試せる環境](/explanation/free-referers/) を参照してください。

## Geolonia CLI とは

API キーを、管理画面ではなくコマンドラインから操作するための公式ツールです。何ができて何に向いているかは [Geolonia CLI とは](/explanation/cli/) を参照してください。
