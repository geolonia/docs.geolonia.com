# Interface: MapElementOptions

## Properties

### apiKey?

> `optional` **apiKey?**: `string`

Geolonia の API キーです。

***

### center?

> `optional` **center?**: [`LatLngLiteral`](/reference/api/geolonia.maps.Interface.LatLngLiteral)

***

### mapId?

> `optional` **mapId?**: `string`

地図インスタンスの識別子です。

***

### mapStyle?

> `optional` **mapStyle?**: `string`

地図のスタイル識別子または URL です。

***

### zoom?

> `optional` **zoom?**: `number`

初期ズームレベルです。
