地図のベーススタイル（道路の色、文字の大きさ、建物の塗りなど）を差し替えます。

## コード

<Lens name="embed">
<Tag k="embed" /> `data-style` 属性にスタイル名または URL を書きます。

```html
<div class="geolonia"
     data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-style="geolonia/gsi"></div>
```

- **`data-style`** — Geolonia が用意するスタイル名（`geolonia/basic`、`geolonia/midnight`、`geolonia/gsi` など）か、外部スタイル JSON の URL を指定できます。
- 省略すると Geolonia の標準スタイルが使われます。

外部の URL を使う例:

```html
<div class="geolonia"
     data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-style="https://tile.openstreetmap.jp/styles/osm-bright/style.json"></div>
```

</Lens>

<Lens name="suite">

> 🚧 suite のコードは準備中です。

</Lens>

<Lens name="react">
<Tag k="react" /> `Map` の `style` プロパティにスタイル名または URL を渡します。state と組み合わせると、**実行時にボタンで切り替える** UI も作れます。

```jsx
import { useState } from "react";
import { Map } from "@geolonia/maps-react";

function App() {
  const [style, setStyle] = useState("geolonia/basic");
  return (
    <>
      <button onClick={() => setStyle("geolonia/basic")}>標準</button>
      <button onClick={() => setStyle("geolonia/gsi")}>地理院</button>
      <Map
        apiKey="YOUR-API-KEY"
        style={style}
        center={[139.75, 35.68]}
        zoom={11}
        containerStyle={{ width: "100%", height: "100vh" }}
      />
    </>
  );
}
```

- **`style`** — スタイル名か、スタイル JSON の URL。state を差し替えるとベース地図が丸ごと切り替わります。
- スタイルを**オブジェクト**（インラインのスタイル定義）で渡す場合は、モジュール定数などにして参照を安定させてください。レンダーのたびに新しいオブジェクトを作ると、毎回スタイルが再読み込みされます。

</Lens>

## 結果

スタイルを `geolonia/gsi` に切り替えた地図です。道路や地名の描き方がデフォルトと変わっています。

<div class="map-box"><div class="geolonia" data-lat="35.68" data-lng="139.75" data-zoom="11" data-style="geolonia/gsi"></div></div>

<Callout title="うまくいかないとき">
- 地図が真っ白になった → スタイル名や URL のつづりを確認。存在しないスタイルを指定すると何も描画されません。
- 属性を書いたのに反映されない → `data-style` のハイフンやつづりを確認。間違った属性名は黙って無視されます。
</Callout>
