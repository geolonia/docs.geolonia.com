店舗や窓口を探す画面でよく見る「地方を選んでから都道府県を選ぶ」地図を作ります。1 回目のクリックで地方を選ぶとその地方に寄り、2 回目のクリックで都道府県を選びます。

日本全体を 1 枚に収めると、沖縄県は九州から遠く離れていて地図が横に広がります。そこで沖縄県は、紙の日本地図と同じように、左上に重ねた小さな地図で見せます。小さな地図に映すのは沖縄本島とその周りで、宮古島や石垣島、大東諸島は映りません。

## データの用意

都道府県の境界を GeoJSON で用意し、各都道府県の `properties` に名前と地方、寄せるときに使う範囲（`west`、`south`、`east`、`north`）を持たせます。

```json
{
  "type": "Feature",
  "geometry": { "type": "MultiPolygon", "coordinates": [ ... ] },
  "properties": {
    "code": 13, "name": "東京都", "region": "関東",
    "west": 138.92, "south": 34.67, "east": 139.89, "north": 35.88
  }
}
```

この例では、[Natural Earth](https://www.naturalearthdata.com/) の 1:1000 万の行政区域（パブリックドメイン）から日本の 47 都道府県を切り出し、八地方区分を `region` に、範囲を `west` などに足した `/data/prefectures.geojson`（約 240KB）を使います。範囲は、東京都の小笠原諸島のように遠く小さな島を除いて計算しています。含めると、寄せたときに地図が太平洋まで広がってしまうためです。範囲を配列ではなく 4 つの数値で持たせているのは、地図のクリックで受け取る `properties` では、配列が文字列に変わってしまうためです。Natural Earth のデータでは奄美群島が沖縄県に入っているので、鹿児島県に移しています。海岸線は粗いので、市区町村まで寄せて見せる用途には向きません。

## コード

3 つの実装方式とも、組み立ては同じです。

1. 本土の地図と、沖縄県を映す小さな地図の 2 つを作り、どちらにも同じ都道府県のデータを `fill` レイヤで重ねる。
2. 選んでいる地方を 1 つの変数で持つ。全国を表示しているときは地方ごとに色を分け、地方を選んだらその地方だけを緑にする。
3. クリックした都道府県の地方が、選んでいる地方と違えば、その地方の範囲に `fitBounds` で寄る。同じなら、その都道府県を選んだことにして、その都道府県の範囲に `fitBounds` で寄る。
4. 地図の外にも、今選べる地方や都道府県をボタンで並べる。地図のクリックだけではキーボードで選べないためです。

地方ごとの範囲は、データから小さな島を除いて計算し、コードに書いています。沖縄県は小さな地図で見せるので、九州・沖縄の範囲には含めていません。

- **`render()`**：全国を表示しているときは地方のボタンを、地方を選んだら「全国に戻る」とその地方の都道府県のボタンを並べます。都道府県の名前と地方は、地図と同じ GeoJSON を `fetch` して取り出します。ボタンを押して並びが変わったときは、先頭のボタンにフォーカスを移し、キーボードで続けて選べるようにしています。2 つの地図にレイヤを足し終えるまでは、ボタンを押せないようにしています（`loaded`）。レイヤができる前に色を切り替えようとすると、エラーになるためです。
- **`aria-live="polite"`**：案内の文が変わったことを、スクリーンリーダーに読み上げてもらうための指定です。
- **`fillColor(region)`**：全国を表示しているとき（`null`）は `match` 式で地方ごとに色を分け、地方を選んだら `case` 式でその地方だけを緑にします。`setPaintProperty` で 2 つの地図の色をまとめて切り替えます。
- **`fitBounds`**：地方を選んだらその地方の範囲に、都道府県を選んだらその都道府県の範囲（`properties` の `west`、`south`、`east`、`north`）に寄ります。最初に全国を表示するときは `duration: 0` で、動かさずに合わせています。
- **小さな地図の `fitBounds`**：下の余白を広く取り、右下の出典表記と沖縄本島が重ならないようにしています。
- **小さな地図の `disable()`**：ドラッグやズームを止め、沖縄本島が枠から外れないようにしています。カーソルも、つかむ形ではなく指の形にしています。
- **小さな地図の `click`**：沖縄本島は細くて押しにくいので、レイヤを指定せず、枠のどこを押しても沖縄県を選んだことにしています。沖縄県の範囲は、`fetch` したデータから `code` が 47 のものを探して使います。

- **ボタン**：embed のタブと同じ `render()` で、地図の上の段に選択肢のボタンを並べます。`#map` の要素を、沖縄県の小さな地図と一緒に入れ物（`stage`）へ移し、ボタンの段の高さが変わっても、小さな地図が本土の地図の左上からずれないようにしています。
- **`gestureHandling: "none"`**：小さな地図をドラッグやズームで動かせないようにします。`disableDefaultUI: true` で、ズームボタンなどの既定のコントロールも消しています。
- **`fitBounds(範囲, 余白)`**：余白は数値 1 つか、`{ top, right, bottom, left }` で指定します。小さな地図は下の余白を広く取り、右下の出典表記と沖縄本島が重ならないようにしています。
- **クリックの受け取り方**：本土の地図は、基盤の地図の `on("click", "prefectures", ...)` で、クリックした都道府県を受け取ります。小さな地図は、沖縄本島が細くて押しにくいので、suite の `addListener("click", ...)` で枠のどこを押しても沖縄県を選んだことにしています。

  const [chosen, setChosen] = useState(null); // 選んだ都道府県の名前
  const [hover, setHover] = useState(false); // カーソルが都道府県の上にあるか
  const [loaded, setLoaded] = useState(0); // 読み込みを終えた地図の数。2 になるまでボタンは押せない

  useEffect(() => {
    fetch("/data/prefectures.geojson")
      .then((res) => res.json())
      .then((data) => setPrefectures(data.features.map((f) => f.properties)));
  }, []);

  useEffect(() => {
    if (!focusChoices.current) return;
    focusChoices.current = false;
    choicesRef.current?.querySelector("button")?.focus();
  }, [selected]);

  function show(region) {
    focusChoices.current = choicesRef.current?.contains(document.activeElement) ?? false;
    setSelected(region);
    setChosen(null);
    mainRef.current?.fitBounds(region === null ? japan : regions[region], { padding: 20 });
  }

  // pref は { code, name, region, west, south, east, north }
  function choose(pref) {
    if (!pref) return;
    if (pref.region !== selected) {
      show(pref.region);
    } else {
      setChosen(pref.name);
      mainRef.current?.fitBounds([[pref.west, pref.south], [pref.east, pref.north]], { padding: 20 });
    }
  }

  const message = chosen
    ? `${chosen}を選びました`
    : selected === null ? "地方を選んでください" : `${selected}：都道府県を選んでください`;

  return (
    <div style={{ display: "flex", flexDirection: "column", height: "100vh", font: "14px/1.6 system-ui, sans-serif" }}>
      <div style={{ padding: "6px 8px" }}>
        <div aria-live="polite">{message}</div>
        {/* 地図の外に、今選べるものをボタンで並べる（キーボードでも選べるようにする） */}
        <div ref={choicesRef} style={{ display: "flex", flexWrap: "wrap", gap: 4, marginTop: 4 }}>
          {selected === null
            ? Object.keys(regions).map((region) => (
                <button key={region} disabled={loaded < 2} onClick={() => show(region)}>{region}</button>
              ))
            : [
                <button key="back" disabled={loaded < 2} onClick={() => show(null)}>全国に戻る</button>,
                ...prefectures.filter((p) => p.region === selected).map((p) => (
                  <button key={p.code} disabled={loaded < 2} onClick={() => choose(p)}>{p.name}</button>
                )),
              ]}
        </div>
      </div>
      <div style={{ position: "relative", flex: 1 }}>
        <Map
          ref={(map) => { mainRef.current = map; }}
          apiKey="YOUR-API-KEY"
          center={[137, 38]}
          zoom={4}
          containerStyle={{ height: "100%" }}
          interactiveLayerIds={["prefectures"]}
          cursor={hover ? "pointer" : ""}
          onMouseEnter={() => setHover(true)}
          onMouseLeave={() => setHover(false)}
          onClick={(e) => e.features?.[0] && choose(e.features[0].properties)}
          onLoad={(map) => {
            map.fitBounds(japan, { padding: 20, duration: 0 });
            setLoaded((n) => n + 1);
          }}
        >
          <Prefectures selected={selected} />
        </Map>
        <div style={{ position: "absolute", top: 8, left: 8, zIndex: 1, width: 150, height: 170, border: "2px solid #555" }}>
          <Map
            apiKey="YOUR-API-KEY"
            center={[127.5, 26.5]}
            zoom={6}
            navigationControl={false}
            containerStyle={{ height: "100%" }}
            cursor="pointer"
            onClick={() => choose(prefectures.find((p) => p.code === 47))}
            onLoad={(map) => {
              map.fitBounds(okinawaArea, { padding: { top: 8, right: 8, bottom: 72, left: 8 }, duration: 0 });
              for (const handler of ["dragPan", "scrollZoom", "doubleClickZoom", "touchZoomRotate", "dragRotate", "keyboard", "boxZoom"]) {
                map[handler].disable();
              }
              setLoaded((n) => n + 1);
            }}
          >
            <Prefectures selected={selected} />
          </Map>
        </div>
      </div>
    </div>
  );
}

createRoot(document.getElementById("root")).render(<App />);

- **`<Prefectures selected={selected} />`**：2 つの地図に同じ都道府県のレイヤを入れる部品です。`selected` が変わると `paint` が変わり、2 つの地図の色が切り替わります。
- **ボタン**：都道府県の名前と地方は、`useEffect` で GeoJSON を `fetch` して `prefectures` に持ちます。`selected` が `null` なら地方のボタンを、地方を選んだら「全国に戻る」とその地方の都道府県のボタンを並べます。ボタンで地方を選んだときは、並び替わったあとの先頭のボタンにフォーカスを移し、キーボードで続けて選べるようにしています。2 つの地図の `onLoad` が終わるまでは、ボタンを押せないようにしています（`loaded`）。読み込み中に地方を選ぶと、そのあとの `onLoad` で全国に戻ってしまい、選んだ地方と表示がずれるためです。
- **`interactiveLayerIds`**：クリックした位置にある `prefectures` レイヤの地物が、`onClick` の `e.features` に入ります。`onMouseEnter` と `onMouseLeave` も、このレイヤへの出入りで呼ばれます。これを使って `cursor` を指の形に切り替えています。
- **`ref` と `onLoad`**：本土の地図は `ref` で地図インスタンスを持っておき、地方を選んだときに `fitBounds` を呼びます。最初の全国表示と、小さな地図の範囲合わせと操作の停止は `onLoad` で行います。
- **小さな地図の `onClick`**：沖縄本島は細くて押しにくいので、`interactiveLayerIds` を付けず、枠のどこを押しても沖縄県を選んだことにしています。

## 結果

上のコードは、それぞれのタブの下でそのまま動いています。最初は日本全体を、地方ごとに色を分けて表示します。関東を押すと関東に寄り、関東の都県だけを緑にします。続けて東京都を押すと「東京都を選びました」と表示されます。左上の沖縄の枠を押すと九州・沖縄を選んだことになり、もう一度押すと沖縄県を選びます。地図の上のボタンでも同じように選べるので、キーボードの Tab キーと Enter キーだけでも操作できます。

実際のサイトでは、「〜を選びました」と表示する代わりに、都道府県ごとのページへ移動したり、一覧を絞り込んだりする処理を書きます。都道府県の `code`（1〜47）は全国地方公共団体コードの都道府県の部分と同じなので、URL やデータの検索に使えます。文字列として使う場合は、`01` のように 2 桁に 0 を補ってください。

<Callout kind="warning" title="うまくいかないとき">
- 地方を押しても寄らない → `regions` のキーと、データの `region` の値が一字一句同じか確認してください。「九州・沖縄」の「・」が全角か半角かでも別の値になります。
- 小さな地図に沖縄県が映らない、または一部が切れる → 小さな地図の大きさを変えたときは、`fitBounds` の余白を合わせて調整してください。
- スマートフォンで地図が狭い → 小さな地図の `width` と `height` を小さくするか、画面幅に応じて切り替えてください。
</Callout>
