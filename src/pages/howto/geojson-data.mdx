GeoJSON ファイルを地図に重ねて、自分のデータ（点・線・面）を表示します。

## コード

<Lens name="embed">
<Tag k="embed" /> `data-geojson` 属性に GeoJSON ファイルの URL を書くだけです。

```html
<div class="geolonia"
     data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-marker="off"
     data-geojson="/data/sample-spots.geojson"></div>
```

- **`data-geojson`** — GeoJSON ファイルのパスまたは URL。同じサーバー上のパスか、CORS を許可した外部 URL を指定します。
- **`data-marker="off"`** — 中心のデフォルトマーカーを非表示にしています。データの点だけを見たいときに便利です。

</Lens>

<Lens name="suite">
<Tag k="suite" /> 地図の読み込みを待ってから、基盤の地図に `addSource`（データ）と `addLayer`（描き方）で重ねます。

```js
import { geolonia } from "@geolonia/maps-suite";

const map = new geolonia.maps.Map(document.getElementById("map"), {
  apiKey: "YOUR-API-KEY",
  center: { lat: 35.68, lng: 139.75 },
  zoom: 11,
});

await map._whenReady();
const impl = map._getImpl();
impl.addSource("spots", { type: "geojson", data: "/data/sample-spots.geojson" });
impl.addLayer({ id: "spots", type: "circle", source: "spots" });
```

- **`_whenReady()` / `_getImpl()`** — ソースやレイヤの操作は高レベル API にないので、読み込み完了を待って基盤の地図（maplibre）に対して行います。
- **`addSource` → `addLayer` の順**で呼びます。`type: "circle"` は各点を丸として描きます。
- CSS のインポートなどセットアップは [maps-suite チュートリアル 段0](/tutorials/maps-suite/first-map/) を参照してください。

</Lens>

<Lens name="react">
<Tag k="react" /> `Map` の子に `Source`（データ）と `Layer`（描き方）を置きます。

```jsx
import { Map, Source, Layer } from "@geolonia/maps-react";

<Map
  apiKey="YOUR-API-KEY"
  center={[139.75, 35.68]}
  zoom={11}
  containerStyle={{ width: "100%", height: "100vh" }}
>
  <Source id="spots" type="geojson" data="/data/sample-spots.geojson">
    <Layer id="spots" type="circle" />
  </Source>
</Map>
```

- **`<Source>`** — `type="geojson"` で、`data` に GeoJSON の URL（またはオブジェクトそのもの）を渡します。
- **`<Layer>`** — データの描き方。`type="circle"` は各点を丸として描きます。**`id` は必須**です——省略するとエラーも出ずにレイヤが追加されず、何も表示されません。
- CSS のインポートなどセットアップは [maps-react チュートリアル 段0](/tutorials/maps-react/first-map/) を参照してください。

</Lens>

## 結果

GeoJSON に含まれる地点がマーカーとして地図に表示されます。

<div class="map-box"><div class="geolonia" data-lat="35.68" data-lng="139.75" data-zoom="11" data-marker="off" data-geojson="/data/sample-spots.geojson"></div></div>

## GeoJSON の形式

GeoJSON は地理データの標準フォーマットです。最小の例はこのようになります。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [139.767125, 35.681236] },
      "properties": { "name": "東京駅" }
    }
  ]
}
```

`coordinates` は **`[経度, 緯度]`** の順です。`data-lat`/`data-lng` とは逆なので注意してください。

<Callout title="うまくいかないとき">
- 点が海に出る → `coordinates` の経度と緯度が逆になっています。`[経度, 緯度]` の順に直してください。
- 何も出ない → ブラウザの開発者ツール（ネットワークタブ）でファイルの HTTP ステータスを確認。404 や JSON の文法エラーが多い原因です。
- 外部 URL の GeoJSON が読めない → CORS の制限です。同じサーバーにファイルを置くか、CORS ヘッダを設定してください。
</Callout>
