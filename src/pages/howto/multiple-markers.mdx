複数の地点をまとめて地図に出します。1点だけなら中心マーカーで十分ですが、**2点以上は「一覧データ＋ループ」** で考えます。座標は `[経度, 緯度]` の順で持ちます。

## コード

<Lens name="embed">
HTML の属性で置けるマーカーは、中心の1本だけです。複数のマーカーは、`new geolonia.Map()` で作った地図に、一覧をループして `geolonia.Marker` を置きます。

<LiveCode title="embed でマーカーを複数置く">

```html
<style>
  body { margin: 0; }
  #map { width: 100%; height: 100vh; }
</style>

<div id="map" data-lat="35.68" data-lng="139.75" data-zoom="11" data-marker="off"></div>

<script src="https://cdn.geolonia.com/embed/v6/embed?geolonia-api-key=YOUR-API-KEY"></script>
<script>
  const points = [
    { name: "東京駅", lng: 139.767125, lat: 35.681236 },
    { name: "新宿駅", lng: 139.700258, lat: 35.690921 },
    { name: "渋谷駅", lng: 139.701636, lat: 35.658034 },
    { name: "浅草寺", lng: 139.796747, lat: 35.714765 },
    { name: "東京タワー", lng: 139.745438, lat: 35.658581 },
  ];

  const map = new geolonia.Map("#map");

  for (const p of points) {
    new geolonia.Marker()
      .setLngLat([p.lng, p.lat])
      .setPopup(new geolonia.Popup().setText(p.name))
      .addTo(map);
  }
</script>
```

</LiveCode>

- **`geolonia.Marker` / `geolonia.Popup`**：embed を読み込むと `window.geolonia` に MapLibre GL JS の中身が入るので、マーカーとポップアップのクラスをそのまま使えます。`setLngLat` は `[経度, 緯度]` の順です。
- **`setPopup()`**：マーカーにポップアップを結び付けます。クリックで開く動きは MapLibre が受け持ちます。`setText` は文字をそのまま入れるので、名前に `<` などが入っていても HTML として解釈されません。
- **`data-marker="off"`**：中心のマーカーを消しています。
- 点を GeoJSON にして `data-geojson` で読み込めば、JavaScript を書かずに複数の点を出せます（→ [外部データ（GeoJSON）を地図に読み込むには](/howto/geojson-data/)）。

</Lens>

<Lens name="suite">
一覧をループして `Marker` を作るだけです。

<LiveCode title="maps-suite でマーカーを複数置く">

```js
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { geolonia } from "@geolonia/maps-suite";

const points = [
  { name: "東京駅", lng: 139.767125, lat: 35.681236 },
  { name: "新宿駅", lng: 139.700258, lat: 35.690921 },
  { name: "渋谷駅", lng: 139.701636, lat: 35.658034 },
  { name: "浅草寺", lng: 139.796747, lat: 35.714765 },
  { name: "東京タワー", lng: 139.745438, lat: 35.658581 },
];

const map = new geolonia.maps.Map(document.getElementById("map"), {
  apiKey: "YOUR-API-KEY",
  center: { lat: 35.68, lng: 139.75 },
  zoom: 11,
});

for (const p of points) {
  new geolonia.maps.Marker({
    position: { lat: p.lat, lng: p.lng },
    map,
    title: p.name,
  });
}
```

</LiveCode>

- **`Marker({ position, map, title })`**：`map` を渡すと、その場でマーカーが地図に取り付けられます。
- クリックでポップアップを出したい場合は、ループ内で `InfoWindow` とクリックリスナーを組み合わせます（→ [クリックでポップアップを出すには](/howto/popup-on-click/)）。

</Lens>

<Lens name="react">
`Marker` はただの React コンポーネントなので、一覧を `map()` で展開するだけです。

<LiveCode title="maps-react でマーカーを複数置く">

```jsx
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { createRoot } from "react-dom/client";
import { Map, Marker } from "@geolonia/maps-react";
import { setWorkerUrl } from "maplibre-gl";
import workerUrl from "maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url";

setWorkerUrl(workerUrl);

const points = [
  { name: "東京駅", lng: 139.767125, lat: 35.681236 },
  { name: "新宿駅", lng: 139.700258, lat: 35.690921 },
  { name: "渋谷駅", lng: 139.701636, lat: 35.658034 },
  { name: "浅草寺", lng: 139.796747, lat: 35.714765 },
  { name: "東京タワー", lng: 139.745438, lat: 35.658581 },
];

createRoot(document.getElementById("root")).render(
  <Map
    apiKey="YOUR-API-KEY"
    center={[139.75, 35.68]}
    zoom={11}
    containerStyle={{ width: "100%", height: "100vh" }}
  >
    {points.map((p) => (
      <Marker key={p.name} lat={p.lat} lng={p.lng}>
        {p.name}
      </Marker>
    ))}
  </Map>,
);
```

</LiveCode>

- **`lat` / `lng`**：マーカーの場所は個別の props で渡します。
- **子要素**：各マーカーをクリックしたときのポップアップになります。
- **`key`**：配列から作るときは忘れずに（ふつうの React のルールです）。

</Lens>

## 結果

上のコードは、それぞれのタブの下でそのまま動いています。一覧に入れた地点すべてにマーカーが立ちます。クリックするとそれぞれの名前がポップアップで開きます。

<Callout kind="warning" title="うまくいかないとき">
- ピンが海に出る → 経度と緯度の取り違え。一覧の `lng` / `lat` を確認してください。
- 数百点あって重い、団子になる → マーカーではなくクラスタリングを使います（→ [大量の点をクラスタリングするには](/howto/clustering/)）。
</Callout>
