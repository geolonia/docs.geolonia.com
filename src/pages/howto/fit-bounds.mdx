複数の地点を置いたとき、`center` と `zoom` を手で決めるのではなく、**全地点を囲む範囲を計算して地図を合わせます**。データが変わっても常に全部が見えます。

## コード

<Lens name="embed">
点を GeoJSON にして `data-geojson` で読み込み、`data-lat` と `data-lng` を書かずにおくと、地図は GeoJSON の全地物が収まる範囲に合わせて表示されます。

<LiveCode title="embed で全地点に画面を合わせる">

```html
<style>
  .geolonia { width: 100%; height: 100vh; }
</style>

<div class="geolonia" data-geojson="/data/sample-spots.geojson"></div>

<script src="https://cdn.geolonia.com/embed/v6/embed?geolonia-api-key=YOUR-API-KEY"></script>
```

</LiveCode>

- **`data-geojson`**：点を並べた GeoJSON ファイルのパスまたは URL。書き方は[外部データ（GeoJSON）を地図に読み込むには](/howto/geojson-data/)にあります。
- **`data-lat` と `data-lng` を書かない**：両方を書くと、その位置が中心になり、範囲には合わせません。中心が無いので、中心のマーカーも表示されません。

</Lens>

<Lens name="suite">
全点の最小と最大の座標から範囲を求めて、`fitBounds` を呼びます。

<LiveCode title="maps-suite で全地点に画面を合わせる">

```js
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { geolonia } from "@geolonia/maps-suite";

const points = [
  { lng: 139.767125, lat: 35.681236 },
  { lng: 139.700258, lat: 35.690921 },
  { lng: 139.701636, lat: 35.658034 },
  { lng: 139.796747, lat: 35.714765 },
  { lng: 139.745438, lat: 35.658581 },
];

const map = new geolonia.maps.Map(document.getElementById("map"), {
  apiKey: "YOUR-API-KEY",
  center: { lat: 35.68, lng: 139.75 },
  zoom: 11,
});

for (const p of points) {
  new geolonia.maps.Marker({ position: p, map });
}

if (points.length > 0) {
  const north = Math.max(...points.map((p) => p.lat));
  const south = Math.min(...points.map((p) => p.lat));
  const east = Math.max(...points.map((p) => p.lng));
  const west = Math.min(...points.map((p) => p.lng));

  map.fitBounds({ north, south, east, west }, 40);
}
```

</LiveCode>

- **`fitBounds({ north, south, east, west }, padding)`**：指定した範囲に地図を合わせます。第2引数は画面の縁からの余白（ピクセル）で、これがないと端の点がぎりぎりに切れます。
- **`points.length > 0`**：点が1つもないと、`Math.max()` が `-Infinity` を返し、範囲を正しく求められません。データを外から読み込むときは、空のまま呼ばないようにします。
- 地図の読み込み完了は `fitBounds()` の中で待つので、呼ぶ前に待つ必要はありません。

</Lens>

<Lens name="react">
`onLoad` で地図インスタンスを受け取り、全点の最小と最大の座標から範囲を求めて `fitBounds` を呼びます。

<LiveCode title="maps-react で全地点に画面を合わせる">

```jsx
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { createRoot } from "react-dom/client";
import { Map, Marker } from "@geolonia/maps-react";
import { setWorkerUrl } from "maplibre-gl";
import workerUrl from "maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url";

setWorkerUrl(workerUrl);

const points = [
  { lng: 139.767125, lat: 35.681236 },
  { lng: 139.700258, lat: 35.690921 },
  { lng: 139.701636, lat: 35.658034 },
  { lng: 139.796747, lat: 35.714765 },
  { lng: 139.745438, lat: 35.658581 },
];

const handleLoad = (map) => {
  if (points.length === 0) return;
  const north = Math.max(...points.map((p) => p.lat));
  const south = Math.min(...points.map((p) => p.lat));
  const east = Math.max(...points.map((p) => p.lng));
  const west = Math.min(...points.map((p) => p.lng));
  map.fitBounds([[west, south], [east, north]], { padding: 40 });
};

createRoot(document.getElementById("root")).render(
  <Map
    apiKey="YOUR-API-KEY"
    center={[139.75, 35.68]}
    zoom={9}
    onLoad={handleLoad}
    containerStyle={{ width: "100%", height: "100vh" }}
  >
    {points.map((p, i) => (
      <Marker key={i} lat={p.lat} lng={p.lng} />
    ))}
  </Map>,
);
```

</LiveCode>

- **`onLoad`**：地図の準備ができたときに、地図インスタンスを引数にして呼ばれます。点が1つもないときは、範囲を計算せずに戻ります。
- **`fitBounds`**：`[[西, 南], [東, 北]]` の範囲に地図を合わせます。`padding` は画面の縁からの余白（ピクセル）で、これがないと端の点がぎりぎりに切れます。

</Lens>

## 結果

上のコードは、それぞれのタブの下でそのまま動いています。初期表示の `center` / `zoom` がどうであれ、読み込み後に全地点が収まる表示範囲に移動します。

<Callout kind="warning" title="うまくいかないとき">
- 端の点が切れる → `padding` を増やしてください。マーカーはピンの高さがあるので、上側は特に余白が要ります。
- 点が1つしかない、または全点が同じ座標 → 範囲の面積が 0 になり、極端にズームインします。点が1つのときは `center` と `zoom` を直接指定する方が簡単です。
</Callout>
