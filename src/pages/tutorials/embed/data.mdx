## GeoJSON を知る

embed で地図にデータを載せるには、**GeoJSON** という形式のファイルを使います。GeoJSON は地理データの標準フォーマットで、テキストエディタで読み書きできる JSON です。

最小の GeoJSON は次のような形をしています。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [139.767125, 35.681236] },
      "properties": { "name": "東京駅" }
    }
  ]
}
```

- **`FeatureCollection`** — 地物（Feature）の入れ物。
- **`geometry`** — 点・線・面などの形状。`coordinates` は **`[経度, 緯度]`** の順です（`data-lat`/`data-lng` とは逆なので注意）。
- **`properties`** — 名前や分類など、地物に付けたい属性。何でも自由に入れられます。

## データを地図に重ねる

GeoJSON ファイルを Web サーバーに置いたら、`div` に `data-geojson` 属性を追加するだけです。

```html
<div class="geolonia"
     data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-marker="off"
     data-geojson="/data/sample-spots.geojson"></div>
```

- **`data-geojson`** — GeoJSON ファイルの URL。同じサーバー上のパスか、CORS を許可した外部 URL を指定します。
- **`data-marker="off"`** — 中心のマーカーを消しています。データの点を見たいときに、中心マーカーがあると紛らわしいので消すのが定番です。

## クラスタリングで見やすくする

データが数十〜数百点になると、点が重なって読めなくなります。`data-cluster="on"` を足すと、近い点を自動でまとめてくれます。

```html
<div class="geolonia"
     data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-marker="off"
     data-geojson="/data/sample-spots.geojson"
     data-cluster="on"></div>
```

拡大するとクラスターが分かれて個別の点になります。色を変えたい場合は `data-cluster-color="#ff0000"` のように指定できます。

実際に描画される地図がこちらです。東京の5地点がマーカーで表示されます。

<div class="map-box"><div class="geolonia" data-lat="35.68" data-lng="139.75" data-zoom="11" data-marker="off" data-geojson="/data/sample-spots.geojson" data-cluster="on"></div></div>

## 自分のデータに差し替える

1. スプレッドシートや CSV で、1行 = 1地点のデータを用意する（経度・緯度の列が必要）。
2. GeoJSON に変換する。手で書いてもよいですし、[geojson.io](https://geojson.io/) などのツールを使うと楽です。
3. ファイルを Web サーバーに置いて、`data-geojson` のパスを差し替える。

## 動いたか確認する

地図上にマーカーが複数表示されていれば成功です。拡大・縮小してクラスターが分かれるのも確認してください。

<Callout title="うまくいかないとき">
- 点が海や別の大陸に出る → **座標の順序**を確認。GeoJSON の `coordinates` は `[経度, 緯度]` です（HTML の `data-lat`/`data-lng` とは逆）。
- 何も出ない → ブラウザの開発者ツール（ネットワークタブ）で GeoJSON のレスポンスを確認。404 や JSON の文法エラーが多い原因です。
- 外部 URL の GeoJSON が読めない → CORS の制限です。まずは同じサーバーにファイルを置いてみてください。
</Callout>
