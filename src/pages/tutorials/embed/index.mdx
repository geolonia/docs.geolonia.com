embed は、Geolonia Maps の中でも**最も簡単に地図を表示する**ためのライブラリです。`<div>` タグと `<script>` タグを HTML に書くだけで動きます。ビルドツールも npm も要りません。テキストエディタとブラウザがあれば始められます。

このチュートリアルでは、能力の梯子を下から順に登ります。各段は短く、必ず動くものを作ります。段5まで登りきると、**自分のデータを載せた地図を、自分の URL で公開できる**ようになります。

1. **段0** [地図を出す](./first-map/)：HTML 1ファイルで地図が出る
2. **段1** [場所と視点](./view/)：見たい場所、拡大率、傾きを指定する
3. **段2** [データを載せる](./data/)：自分の地点データ（GeoJSON）を重ねる
4. **段3** [見た目を変える](./style/)：ベース地図のスタイルを差し替える
5. **段4** [対話を足す](./interaction/)：クリックでポップアップを出す
6. **段5** [公開する](./publish/)：API キーを用意して本番公開する

途中でつまずいても大丈夫です。各段に「うまくいかないとき」の確認ポイントを用意しています。

まずは [段0：地図を出す](./first-map/) から始めましょう。
