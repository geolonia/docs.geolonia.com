embed は、Geolonia Maps の中で**記述量が最も少ない**ライブラリです。`<div>` タグと `<script>` タグを HTML に書くだけで動作し、ビルドツールと npm は必要ありません。

このチュートリアルは6つの Step で構成されています。各 Step は独立して動作するコードで完結します。Step 5 まで進むと、**自分のデータを載せた地図を、自分の URL で公開する**ところまで到達します。

1. **Step 0** [地図を表示する](./first-map/): HTML ファイル1つで地図を表示する
2. **Step 1** [初期位置とズームの設定](./view/): 中心座標、拡大率、傾きを指定する
3. **Step 2** [マーカーとデータの追加](./data/): 地点データ（GeoJSON）を重ねる
4. **Step 3** [地図スタイルの適用](./style/): ベース地図のスタイルを差し替える
5. **Step 4** [イベント処理とポップアップ](./interaction/): クリックでポップアップを表示する
6. **Step 5** [API キーの設定と本番公開](./publish/): API キーを発行して本番公開する

各 Step の末尾には、想定される失敗と確認手順をまとめた「うまくいかないとき」を用意しています。

最初の手順は [Step 0: 地図を表示する](./first-map/) です。
