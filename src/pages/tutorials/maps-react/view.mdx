# 地図の場所やズームレベルの指示方法

地図が表示できたら、次は表示したい地点を表示したい大きさで表示してみましょう。

`Map`コンポーネントに以下を付け加えるだけです。

```
<Map
  center={[139.767125, 35.681236]} // 追加
  zoom={14} // 追加
  containerStyle={{ width: "100%", height: "100vh" }}
/>
```

`center`は中心(経度、緯度の順番)を指し、`zoom`はズームレベル(大きいほど狭い範囲を表示)になります。
