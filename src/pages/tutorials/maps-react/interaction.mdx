## Marker コンポーネント

maps-react には、地図上の1点に立てる `Marker` コンポーネントがあります。`Map` の子として置き、`lat` / `lng` で場所を指定します。

そして、ここが maps-react らしいところです。**`Marker` の子要素が、そのままポップアップの内容になります**。

<LiveCode title="maps-react でマーカーとポップアップを出す">

```jsx
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { createRoot } from "react-dom/client";
import { Map, Marker } from "@geolonia/maps-react";

createRoot(document.getElementById("root")).render(
  <Map
    apiKey="YOUR-API-KEY"
    center={[139.767125, 35.681236]}
    zoom={15}
    containerStyle={{ width: "100%", height: "100vh" }}
  >
    <Marker lat={35.681236} lng={139.767125} color="#e4402f">
      <strong>東京駅</strong>
      <p style={{ margin: 0 }}>JR・地下鉄各線</p>
    </Marker>
  </Map>,
);
```

</LiveCode>

- **`lat` / `lng`**：マーカーを立てる場所。`Map` の `center`（`[経度, 緯度]` の配列）と違い、こちらは**個別の props** で渡します。
- **`color`**：マーカーの色。
- **子要素**：マーカーをクリックしたときに開くポップアップの中身。JSX なので、React コンポーネントも含めて自由に書けます。

## データから複数のマーカーを作る

`Marker` はただの React コンポーネントなので、配列から `map()` で並べれば、データ駆動で複数のマーカーが立ちます。

```jsx
const spots = [
  { name: "東京駅", lat: 35.681236, lng: 139.767125 },
  { name: "新宿駅", lat: 35.690921, lng: 139.700258 },
  { name: "渋谷駅", lat: 35.658034, lng: 139.701636 },
];

<Map apiKey="YOUR-API-KEY" center={[139.73, 35.68]} zoom={12}
     containerStyle={{ width: "100%", height: "100vh" }}>
  {spots.map((s) => (
    <Marker key={s.name} lat={s.lat} lng={s.lng}>
      <strong>{s.name}</strong>
    </Marker>
  ))}
</Map>
```

state と組み合わせれば、「一覧をクリックすると地図のマーカーが増える」のような UI も、ふつうの React の書き方だけで作れます。

## 動いたか確認する

マーカーをクリックして、書いた JSX の内容がポップアップに出れば成功です。もう一度クリックすると閉じます。

<Callout kind="warning" title="うまくいかないとき">
- マーカーが変な場所に出る → `lat` と `lng` の**取り違え**を確認。`center` は `[経度, 緯度]` の配列ですが、`Marker` は `lat=` `lng=` と名前付きで渡します。
- ポップアップが開かない → 子要素が空になっていないか確認。子要素のない `Marker` はポップアップなしのマーカーになります。
- 複数のマーカーで警告が出る → 配列から作るときは `key` を忘れずに（ふつうの React のルールです）。
</Callout>
