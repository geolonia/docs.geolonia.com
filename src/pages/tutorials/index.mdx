# Geolonia Maps チュートリアル

Geolonia Mapsを使って実用的な地図アプリケーションを作ってみましょう。このチュートリアルでは、以下のことができます。

- 地図を表示する
- 地図の見た目を変える
- 地図にマーカーを表示する
- 地図に独自データを反映させる

## 自分に合ったライブラリを選ぶ

Geolonia Mapsでは、3つのライブラリを用意しており、同じ機能をやりやすいやり方で実現することができます。

- embed: `<script>`タグと`<div>`タグだけで地図を表示できます。「とりあえず地図が欲しい！」という初心者向けライブラリです。
- maps-suite: 他の地図サービスからの移行に適したライブラリです。既存ユーザーが導入しやすいようなAPI設計をしてあります。
- maps-react: Reactに対応したライブラリです。マーカーやデータの切り替えなどを動的に行うことができます。

これら3つのライブラリは、maps-coreというMapLibre GL JSをGeoloniaの提供する地図に対応させたライブラリをベースに作られているため、TypeScriptコードを書けばMaplibre GL JSに対応したすべての機能が実現できます。
