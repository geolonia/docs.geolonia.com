## ① 用意したデータを出す

地図の `div` に `data-geojson` を1つ足すだけ。まずはこちらで用意したサンプル（東京の5地点）で動かします。レンズ切替でコードが変わります。

<Lens name="embed">
<p><Tag k="embed" /> 宣言型。属性に GeoJSON の URL を渡すだけ。</p>

```html
<div class="geolonia" data-lat="35.68" data-lng="139.75" data-zoom="11"
     data-geojson="/data/sample-spots.geojson"></div>
```
</Lens>

<Lens name="suite">
<p><Tag k="suite" /> 命令型。<code>addSource</code> ＋ <code>addLayer</code> で重ねる。</p>

```js
map.on('load', () => {
  map.addSource('spots', { type: 'geojson', data: '/data/sample-spots.geojson' });
  map.addLayer({ id: 'spots', type: 'circle', source: 'spots' });
});
```
</Lens>

<Lens name="react">
<p><Tag k="react" /> 宣言型コンポーネント。</p>

```jsx
<Source id="spots" type="geojson" data="/data/sample-spots.geojson">
  <Layer type="circle" />
</Source>
```
</Lens>

## ② 自分のデータに差し替える

<ol class="steps">
  <li><h3>CSV に経度・緯度の列を用意する</h3><span class="obj">到達目標：1行 = 1地点で座標を持てている</span></li>
  <li><h3>GeoJSON に変換する</h3><span class="obj">到達目標：自分の一覧が FeatureCollection になっている</span></li>
  <li><h3><code>data-geojson</code> の参照先を差し替える</h3><span class="obj">到達目標：自分のデータの点が地図に出る</span></li>
</ol>

<Callout title="つまずいたら">
- 点が海に出る → 座標が <code>[緯度, 経度]</code> 逆。<code>[経度, 緯度]</code> に直す。
- 何も出ない → URL の 404 か GeoJSON の文法エラー。ファイルを直接開いて確認。
- 外部 URL が読めない → CORS。まず同一オリジンに置く。
</Callout>
