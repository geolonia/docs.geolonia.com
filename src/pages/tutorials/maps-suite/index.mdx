maps-suite は、Geolonia Maps を **JavaScript から命令的に操作する**ためのライブラリです。`Map`、`Marker`、`InfoWindow` といった、他の地図サービスを使ったことがあれば見覚えのあるクラス構成で、「地図を作る → メソッドで操作する」という素直な書き方ができます。フレームワークを問わず、どんな Web ページにも組み込めます。

このチュートリアルでは、能力の梯子を下から順に登ります。各段は短く、必ず動くものを作ります。段5まで登りきると、**自分のデータを色分けして載せた地図を、自分の URL で公開できる**ようになります。

1. **段0** [地図を出す](./first-map/)：`new geolonia.maps.Map()` で地図が出る
2. **段1** [場所と視点](./view/)：見たい場所、拡大率、傾きを指定する
3. **段2** [データを載せる](./data/)：自分の地点データ（GeoJSON）を重ねる
4. **段3** [見た目を変える](./style/)：データの属性に応じて点を色分けする
5. **段4** [対話を足す](./interaction/)：マーカーのクリックで情報ウィンドウを出す
6. **段5** [公開する](./publish/)：ビルドして本番公開する

途中でつまずいても大丈夫です。各段に「うまくいかないとき」の確認ポイントを用意しています。

まずは [段0：地図を出す](./first-map/) から始めましょう。
