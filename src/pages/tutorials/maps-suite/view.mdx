## 場所と拡大率を指定する

場所と拡大率は、`Map` を作るときの**オプション**で指定します。場所は `center`、拡大率は `zoom` です。

```js
const map = new geolonia.maps.Map(document.getElementById("map"), {
  apiKey: "YOUR-API-KEY",
  center: { lat: 35.658581, lng: 139.745438 },
  zoom: 16,
});
```

- **`center`**：地図の中心。`{ lat: 緯度, lng: 経度 }` のオブジェクトで渡します。上の値は東京タワーです。自分の見たい場所の座標は、Google マップ等で右クリックすると取得できます。
- **`zoom`**：拡大率。数字が大きいほど寄ります。目安は、**11** で都市の全体、**14** で街区、**16** で建物が見えるくらいです。

作った後から動かすこともできます。`map.setCenter({ lat, lng })` で移動、`map.panTo({ lat, lng })` でアニメーション付きの移動、`map.setZoom(14)` で拡大率の変更です。

## 視点を傾けて回す

視点の傾き（pitch）と回転（bearing）は、maps-suite の高レベル API にはありません。こういうときのために、**基盤の地図（maplibre）に直接触るためのエスケープハッチ**が用意されています。

ここまでを入れた `main.js` の全体が次のコードです。

<LiveCode title="maps-suite で東京タワーを傾けて見る">

```js
import "maplibre-gl/dist/maplibre-gl.css";
import "@geolonia/maps-core/css";
import { geolonia } from "@geolonia/maps-suite";

const map = new geolonia.maps.Map(document.getElementById("map"), {
  apiKey: "YOUR-API-KEY",
  center: { lat: 35.658581, lng: 139.745438 },
  zoom: 16,
});

map._whenReady().then(() => {
  const impl = map._getImpl();
  impl.setPitch(45);    // 地図を手前に倒す角度（度）。0 が真上からの平面図
  impl.setBearing(20);  // 地図を回す角度（度）。0 が北が上
});
```

</LiveCode>

- **`map._whenReady()`**：地図の読み込み完了を待つ Promise を返します。
- **`map._getImpl()`**：基盤の maplibre の地図インスタンスを返します。maps-suite にない操作はすべてここから呼べます。

この「読み込みを待ってから `_getImpl()` で触る」という形は、次の段のデータ追加でも使う maps-suite の基本パターンです。

## 動いたか確認する

中心が東京タワーになり、地図が斜めから見た構図になっていれば成功です。`center` を自分の場所に差し替えて、狙った場所が中心に出ることも確かめてください。

<Callout kind="warning" title="うまくいかないとき">
- 中心が海や別の国に飛ぶ → `lat` と `lng` の**取り違え**を確認。日本国内なら `lat` はおよそ 24〜46、`lng` はおよそ 123〜146 です。
- `setPitch` などで「関数がない」エラー → `map` 本体ではなく `map._getImpl()` の戻り値に対して呼んでいるか確認。
- 傾きが反映されない → `_whenReady()` を待ってから呼んでいるか確認。
</Callout>
