Geolonia Maps の料金は、地図を読み込んだ回数（[地図表示回数](#地図表示回数とは)）に応じて決まります。料金は円建てで、すべて税抜の金額で記載しています（税込の金額を併記している箇所を除く）。

## プラン

| | Free | Pro |
|---|---|---|
| 月額 | 無料 | {fmt(PRO_MONTHLY_JPY)} 円（税込 {fmt(withTax(PRO_MONTHLY_JPY))} 円） |
| 月額に含まれる地図表示回数 | {fmt(FREE_LOADS)} 回まで | {fmt(PRO_INCLUDED_LOADS)} 回まで |
| 含まれる回数を超えた分 | Pro プランをご利用ください | 従量課金（[下の表](#従量課金)） |
| メンバーの追加 | できます | できます |
| API キーの発行 | できます | できます |
| 支払い方法 | なし | クレジットカード |

月に {fmt(FREE_LOADS)} 回を超えて地図を表示する場合は、Pro プランをご利用ください。プランの変更と地図表示回数の確認は、[ダッシュボード](https://app.geolonia.com/)の「料金プランとお支払い」で行います。

開発環境とプレビュー環境（`localhost`、GitHub Pages など）は、API キーを発行しなくても**デモキー**を使って地図を表示できます。対象の環境の一覧は「[デモキーで無料で試せる環境](/explanation/free-referers/)」にあります。

## 従量課金

Pro プランでは、月の地図表示回数が {fmt(PRO_INCLUDED_LOADS)} 回を超えると、超えた分に次の単価がかかります。回数が増えるほど単価は下がります。

## 地図表示回数とは

地図がユーザーの端末で読み込まれた回数です。ページを読み込むごとに 1 回と数え、同じページに同じ API キーの地図が複数あっても 1 回です。ページを読み込み直さずに画面を切り替えるサイト（シングルページアプリケーション）では、ページを読み込み直すまでが 1 回です。ただし、回数は 1 日（日本時間の 9 時から翌日の 9 時まで）ごとに集計するので、開いたままのページで日をまたいでから地図を作り直すと、もう 1 回数えます。iframe の中に置いた地図は、外側のページとは別に数えます。

数えるのは、地図を作って、地図のデータの読み込みが始まった時点です。[embed](/tutorials/embed/first-map/) で HTML の要素として置いた地図は、画面に入るまで作られません。そのため、地図がページの下のほうにあり、画面に表示されなかった場合は数えません。ただし、`data-lazy-loading="off"` を付けた地図と、`new geolonia.Map()` で作った地図はすぐに作られるので、画面に表示されなくても数えます。maps-core、maps-react、maps-suite は、地図を作った時点で数えます。

## サイトの規模の目安

ページビュー（PV）のうち地図が表示される割合によって、同じ表示回数で賄える PV は変わります。すべてのページに地図がある場合を 1 倍、平均して 25 PV に 1 回地図が表示される場合を 25 倍として見積もると、次のようになります。

| | Free | Pro（月額のみ） |
|---|---|---|
| 地図表示回数 | {fmt(FREE_LOADS)} 回まで | {fmt(PRO_INCLUDED_LOADS)} 回まで |
| サイトの月間 PV | {fmt(FREE_LOADS)} 〜 {fmt(FREE_LOADS * 25)} | {fmt(PRO_INCLUDED_LOADS)} 〜 {fmt(PRO_INCLUDED_LOADS * 25)} |

イベントや不動産のサイトのように地図のあるページが多いサイトでは、1 倍に近くなります。同じページに同じ API キーの地図を何枚置いても、1 回のページの読み込みで数えるのは 1 回です。

## 支払いのサイクル

- **Pro プランの月額**：初回分は Pro プランへの登録日に請求します。以降は毎月、チームの登録日と同じ日に請求します。
- **従量課金**：チームを登録した日から 1 か月分を集計し、翌月の同じ日に請求します。

チームは Geolonia Maps への登録日に自動で作られます。チームは複数作れます。

## ほかの地図 API から切り替える場合

Google Maps や Mapbox をお使いの場合は、[コスト削減診断](/pricing/cost-reduction/)で、先月のおおよその請求額から Geolonia Maps の月額を試算できます。
